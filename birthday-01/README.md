# Birthday code rain

Full-screen responsive pink code rain with a blurred tap-to-continue opening.

1. The first tap removes the blur and starts both the countdown and supplied song.
2. The countdown and birthday words lead to a centered pink cake built from HTML divs and CSS and an envelope with an unread badge.
3. Open the envelope to read the editable love letter. Opening clears its badge.

The cake uses only HTML divs and CSS gradients: cylinder frosting, layered rose petals, gold leaf, piped pearls, and porcelain pedestal. The supplied photo is a visual reference only. Music: PST-wish-page-theme.mp3, stored in assets.
Personalize the name with ?name=Alex. Edit the letter inside index.html.
Music loops through the cake/letter scene. Sound toggles mute; pause pauses animation and song; replay restarts both. Hidden tabs pause playback.
Reduced-motion settings skip the intro animation after the tap and retain a stationary code background.
